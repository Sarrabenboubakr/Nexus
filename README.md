# nexus_4DAS16-g4

Projet **Nexus**, classe **4DAS16**, groupe **g4**.

Plateforme de gestion de projets : organisations, projets, tâches, documents, collaboration, utilisateurs et audit.

## Structure

```
nexus_4DAS16-g4/
├── Backend/
│   ├── organisation/
│   ├── projet/
│   ├── task/
│   ├── document/
│   ├── collaboration/
│   ├── user/
│   └── audit/
├── Frontend/
├── Documentation/
│   ├── Presentation/
│   ├── Diagrams/
│   └── Dossier-technique/
└── README.md
```

## Microservices

| Service | Rôle |
| --- | --- |
| `organisation` | Organisations et leurs membres |
| `projet` | Projets rattachés à une organisation |
| `task` | Tâches d’un projet |
| `document` | Documents associés à un projet |
| `collaboration` | Invitations, partages et travail en commun |
| `user` | Comptes, authentification et profils |
| `audit` | Journal des actions sur la plateforme |
